# 現場ラジオデータ

「現場ラジオデータ」は、YouTubeチャンネル「現場ラジオ」の運営者が、自分のチャンネルの数字を集めるためだけに使う仕組みです。一般の方が使うアプリではありません。

## プライバシーポリシー

**使う情報**：「現場ラジオ」チャンネルのYouTubeアナリティクスの数字と、公開動画の一覧だけです。視聴者一人ひとりを特定できる情報は扱いません。

**Googleドライブ**：この仕組みが自分で作ったファイルにだけ、集めた数字の表を書き出します。ほかのファイルは読みません。

**共有**：集めた情報を第三者に渡したり、売ったりしません。広告にも使いません。

**保存場所**：運営者の非公開のGitHubリポジトリと、運営者のGoogleドライブです。

**許可の取り消し**：Googleアカウントの「サードパーティ製のアプリとサービス」から、いつでも取り消せます。

**Googleのユーザーデータ**：Google API サービスのユーザーデータに関するポリシーに従って扱います。
